# Generated samples

These examples were created with the prompt-to-OpenSCAD workflow and rendered
locally with OpenSCAD 2021.01. Each folder contains editable `source.scad`, a
PNG preview, and any successfully exported STL parts.

| Sample | Files | Notes |
|---|---|---|
| `sliding-box-80x50x25` | body and lid STL | 80 x 50 x 25 mm, 2 mm walls, 4 mm corners, 0.30 mm sliding clearance |
| `infant-grasp-ring-concept` | one prototype STL | CAD concept only; **not certified or suitable for infant use** |
| `ranger-style-armed-pickup` | body, wheel and turret STL | Generic pickup styling; print four wheels; detachable parts are a choking hazard |
| `wheeled-excavator-assembly` | carrier, wheel and boom/bucket STL | Generic wheeled excavator; print four wheels; 0.40 mm assembly clearance |

STL files are unsliced geometry. Inspect every mesh, verify tolerances with a
small test print, and slice it for the actual printer/material profile before
printing. The infant concept has not undergone toy-safety, material, impact,
torque, tension, compression, hygiene, or choking-fixture testing.
